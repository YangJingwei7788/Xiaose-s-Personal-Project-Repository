02.设计思路
  模型部署：使用 Ollama 在本地完成 deepseek-r1:8b 大模型部署，提供本地 API 推理服务。 
  LLM 调度：基于 OpenAI 兼容接口编写基础调用逻辑，自动携带系统人设提示词，流式输出
  上下文联系方式：滚雪球式，对话直接保存在 json 中，每次对话自动带入历史对话内容，实现上下文连续对话，设置最大关联条数，缓解程序运行压力。
  Web 前端：采用 Streamlit 搭建轻量化网页交互界面，提供聊天输入、流式输出展示。
  会话管理：实现历史对话本地 json 持久化，支持对话新建、保存、加载、删除功能。
