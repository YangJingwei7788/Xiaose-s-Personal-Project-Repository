# 家具回收售卖展示系统（codex+deepseek辅助开发）

面向门店/毕设场景的极简业务展示系统：**仅展示可回收/可售卖的物品种类、业务范围、服务介绍，并支持客户在线预约咨询**，无商品详情、价格、库存等冗余功能。

## 功能

- 客户前台：首页业务总览、回收品类展示、售卖品类展示、门店服务介绍、通用预约弹窗、**顶部自动轮播大图**
- 商家后台（`/admin.html`，固定密码登录，默认 `admin123`）：
  - 品类管理：新增、编辑、删除、显示/隐藏回收与售卖品类，自定义排序；**可为每个品类上传一张图片作为前台卡片背景**，上传后可即时预览、随时更换或移除
  - 预约管理：查看全部客户预约、标记已处理/未处理、删除记录
  - 基础设置：编辑店铺名称、标语、各页文案、服务优势、上门服务、地址、电话、营业时间、后台密码
  - **轮播图管理：可上传多张图片替换首页/回收/售卖/门店介绍页顶部的自动轮播图**，支持预览、删除、一键恢复默认
- 图片上传：支持 jpg/jpeg/png/gif/webp，单张 ≤5MB，上传后保存在 `uploads/` 目录（打包后为 EXE 同目录 `uploads/`），重启不丢失
- 纯本地运行：SQLite 单文件数据库（`furniture.db`），无需联网、无环境依赖
- 支持局域网访问：同 WiFi 设备通过电脑内网 IP 即可浏览、提交预约
- 可打包为单文件 EXE，双击即用，自动打开浏览器

## 目录结构

```
furniture_show_system/
├─ main.py               # FastAPI 主程序、服务入口
├─ database.py           # 数据库连接、自动建表、迁移、种子数据
├─ models.py             # 数据表结构与默认数据定义
├─ schemas.py            # 请求数据校验
├─ routers/
│  ├─ category.py        # 品类展示、品类管理接口
│  ├─ book.py            # 客户预约接口
│  └─ admin.py           # 后台登录、配置、图片上传接口
├─ uploads/              # 后台上传的图片（品类图、轮播图）
└─ static/               # 前端静态页面（随 EXE 打包）
   ├─ index.html         # 首页-业务总览
   ├─ recycle.html       # 回收品类展示页
   ├─ sell.html          # 售卖品类展示页
   ├─ about.html         # 门店服务介绍页
   ├─ admin.html         # 后台-品类/预约/设置/轮播图管理
   ├─ style.css          # 统一样式（DeepSeek 风格）
   ├─ common.js          # 公共脚本（导航/轮播/预约弹窗/API）
   └─ img/               # 默认轮播与占位图片
```

## 数据库

- `goods_category`：业务品类表（id, name, type 1=回收/2=售卖, sort, status 1=显示/0=隐藏, image 背景图, create_time）
- `customer_book`：客户预约表（id, name, phone, book_type 1=回收/2=购买, need_content, create_time, status 0=未处理/1=已处理）
- `settings`：门店配置表（key, value），含后台密码、轮播图配置

首次启动自动建表并写入默认种子数据（默认品类、默认文案、默认后台密码 `admin123`）；旧版本数据库启动时自动迁移补齐新增字段。

## 开发运行

```bash
# 安装依赖（Python 3.13+）
python -m venv .venv
.venv\Scripts\activate
pip install fastapi uvicorn python-multipart

# 启动服务（默认 0.0.0.0:8000）
python main.py
```

启动后自动打开浏览器（默认进入商家后台）；如需指定端口：`python main.py --port 9000`；不自动打开浏览器：`python main.py --no-browser`。


## 使用说明

1. 双击 EXE 启动，控制台会打印本机与局域网访问地址，并自动打开浏览器（**默认直接进入商家后台** /admin.html）
2. 客户访问首页/回收/售卖/门店介绍页浏览业务，点击「立即预约」填写姓名、电话、类型、需求提交预约
3. 管理员访问 `http://127.0.0.1:8000/admin.html`，输入默认密码 `admin123` 登录（建议登录后在「基础设置」中修改密码）
4. **品类图片**：在「品类管理」中点击某品类的「上传图」，选择图片即可；上传后前台该品类卡片会以图片为背景，点「移除图」可恢复图标样式
5. **轮播图**：在「轮播图」页面上传（可多选），上传的图片会替换所有前台页面顶部的自动轮播；「删除」可移除单张，「恢复默认」回到系统自带图片
6. 数据保存在 EXE 同目录的 `furniture.db` 与 `uploads/` 文件夹，重启程序数据不丢失；删除 `furniture.db` 可恢复出厂默认数据

## 常见问题

- 端口被占用：启动时指定 `--port 9000` 等空闲端口
- 局域网无法访问：确认电脑防火墙放行对应端口；手机与电脑需在同一 WiFi
- 打包后的 EXE 目录需可写（用于保存 `furniture.db` 与 `uploads/`）
- 上传图片格式/大小不符会被拒绝（仅 jpg/png/gif/webp，≤5MB）
