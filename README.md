02.设计思路  
	模型部署：使用 Ollama 在本地完成 deepseek-r1:8b 大模型部署，提供本地 API 推理服务。    
  	LLM 调度：基于 OpenAI 兼容接口编写基础调用逻辑，自动携带系统人设提示词，流式输出。  
  	上下文联系方式：滚雪球式，对话直接保存在 json 中，每次对话自动带入历史对话内容，实现上下文连续对话，设置最大关联条数，缓解程序运行压力。  
  	Web 前端：采用 Streamlit 搭建轻量化网页交互界面，提供聊天输入、流式输出展示。  
	会话管理：实现历史对话本地 json 持久化，支持对话新建、保存、加载、删除功能。  
03.自我评价  
	优点：  
	1. 支持对接本地部署大模型，也可兼容各类主流大模型API，适配灵活  
	2.Streamlit搭建网页，界面开发便捷，上手简单  
	3.可预先设定AI角色人设，稳定统一AI输出风格  
	缺点：  
	1.采用滚雪球式上下文机制，对话持续推进后算力开销上升，推理速度变慢  
	2.Streamlit构建网页原生运行性能一般，程序容易出现卡顿  
	3.暂未接入搜索接口，模型无法联网获取实时资讯  
	优化方案：  
	1.引入对话摘要策略压缩历史消息，搭配向量数据库实现选择性调取历史对话；  
	2.采用 FastAPI+Vue 进行前后端分离重构；  
	3.接入搜索引擎 API，利用模型工具调用能力，实现联网检索；
